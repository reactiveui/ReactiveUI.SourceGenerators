# bindings

Binding APIs: `BindOneWay`, `BindTwoWay`, `OneWayBind`, `Bind`, `BindTo`, `BindCommand`, `BindInteraction` and
`InvokeCommand`.

- One-way and two-way bindings, with converters and hints.
- Commands and interactions between a view and its view model.
- Binding hooks, binding errors and custom command binders.

```sh
dotnet run --project src/examples/Documentation/Pages/bindings -f net10.0
```
