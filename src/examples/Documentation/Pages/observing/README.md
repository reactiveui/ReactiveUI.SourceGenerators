# observing

Observing properties: `WhenChanged`, `WhenChanging`, `WhenAny`, `WhenAnyValue` and `WhenAnyObservable`.

- Property paths, several properties at once, and the values they deliver.
- `IObservedChange`, buffering, sampling, windows and running totals.
- Search-as-you-type and other composed observations.
