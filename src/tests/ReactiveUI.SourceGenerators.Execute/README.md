# ReactiveUI.SourceGenerators.Execute

Runnable examples of the attribute generators. Each class uses `[Reactive]`, `[ReactiveCommand]`, `[IReactiveObject]`,
`[ObservableAsProperty]` or a control host, and the program runs the generated members.

```sh
dotnet run --project src/tests/ReactiveUI.SourceGenerators.Execute -f net10.0
```
